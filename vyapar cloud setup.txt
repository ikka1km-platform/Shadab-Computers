### Step-by-Step: Deploy to Render.com (100% Free)

#### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and log in.
2. Click the green **"New"** button to create a new repository (name it something like `vyapar-cloud`).
3. You can set it to **Private** or **Public**, then click **Create repository**.
4. Copy the repository link (e.g., `https://github.com/your-username/vyapar-cloud.git`).

---

#### Step 2: Push your project to GitHub
In your project folder (`C:\VYApaar with cash counter`), open PowerShell or Command Prompt and run:

```bash
git add .
git commit -m "Configure 24/7 cloud server"
git remote add origin https://github.com/<your-username>/vyapar-cloud.git
git push -u origin master
```

*(I have already created the `render.yaml` configuration and start scripts in your project so Render detects everything automatically).*

---

#### Step 3: Deploy on Render.com
1. Go to **[render.com](https://render.com)** and click **Sign Up** ➔ choose **Continue with GitHub**.
2. Click the **"New +"** button at the top right and select **Web Service**.
3. Select your **`vyapar-cloud`** repository.
4. Render will show the settings:
   * **Name:** `shadab-vyapar` (or whatever you prefer)
   * **Region:** Singapore or Frankfurt (fastest for India)
   * **Instance Type:** **Free**
   * **Build Command:** `npm install && npm run build`
   * **Start Command:** `npm start`
5. Click **Deploy Web Service**.

---
